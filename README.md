# Nexus AI 🚀

Aplikasi Android futuristik dengan UI glassmorphism/neon untuk kontrol sistem AI.

## Fitur
- 🎨 UI Glassmorphism + Neon gradient
- 🌐 Multi-bahasa (EN / ID)
- 📝 TextBox dengan custom icon
- 🎛️ Switch, Slider, Dropdown
- 💬 Dialog Konfirmasi
- 🔔 Notifikasi (Android 13+ support)
- 📡 Log informasi live

## Build

./gradlew assembleRelease
